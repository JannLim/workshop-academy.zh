# DR-001: 学员自助报名与管理

## 状态

已接受（2026-11-11）

## 背景

- 课程目录和已发布课程详情目前可公开浏览，但没有报名能力。
- 最小可验证版本需要让学员完成报名、查看和取消报名的闭环，并隔离不同学员的数据。
- 报名不限人数，不需要容量、审批或候补机制。

## 决策

### 报名生命周期与归属

| 事项 | 决策 |
| --- | --- |
| 报名主体 | 仅已登录的学员可为自己报名，报名归属由当前登录身份确定 |
| 报名对象 | 仅允许报名当前已发布的课程 |
| 生效条件 | 学员主动提交报名并成功后立即生效，不收费、不审批、不限制人数 |
| 有效报名 | 已成功报名且未取消，不设有效期 |
| 唯一性 | 同一学员对同一课程最多存在一份有效报名，重复或并发提交不产生重复有效报名 |
| 自助管理 | 学员可查看和取消自己的报名，不能查看、创建或修改他人的报名 |
| 取消 | 取消成功后报名不再有效，重复取消不重新生效，也不影响其他报名 |
| 再次报名 | 取消后可重新报名当前已发布课程 |
| 管理员 | 本版本不提供管理员报名、代报名或管理学员报名的能力 |

### 最小产品流程

- 课程目录和已发布课程详情继续公开浏览，不因未登录或未报名而隐藏。
- 未登录访客在课程详情看到“登录后报名”，登录成功返回原课程，由学员主动点击报名，不自动提交。
- 未报名学员在课程详情看到“立即报名”，成功后看到“开始观看”。
- 学员通过“我的报名”入口查看当前有效报名，并进入课程或取消报名。
- “我的报名”为空时提供返回课程目录的入口。
- 取消操作明确提示将失去观看资格，成功后该项从当前报名列表移除。
- 已报名课程取消发布后，列表保留该报名并标示“课程暂不可用”，允许取消，但不开放未发布课程详情。
- 课程发布状态与观看资格的关系由 [DR-002](002-enrollment-watch-eligibility.md) 决定。
- 报名及取消结果的持久化由 [DR-003](003-enrollment-data-continuity.md) 决定。

### 范围边界

- 本版本不提供已取消报名历史、报名人数展示、搜索筛选、批量操作、报名资料编辑或报名转让。
- 本版本不引入收费、审批、候补、报名期限或账号注册功能。
- 报名取消历史的存储方式不属于本业务决策。

## 影响

- 需要增加“我的报名”入口及列表，并扩展课程详情的报名状态与操作反馈。
- 服务端必须执行报名归属限制，页面隐藏操作不能代替权限检查。
- 可通过报名、重复提交、取消、再次报名及两个学员之间的越权操作验证生命周期与隔离边界。
- 下架课程的报名仍可管理，避免学员因课程不可访问而无法取消报名。
