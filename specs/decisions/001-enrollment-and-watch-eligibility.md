# DR-001: 报名与观看资格

## 状态

已接受

## 背景

学堂在线当前允许任何已登录账号直接观看已发布课程，没有报名概念。
课程目录和课程详情对所有访客公开。
产品要求增加报名，报名人数不限，同时保持目录和详情公开浏览。
最小版本不引入支付、审批、名额、候补或学习进度，以缩小实现和验证范围。
本决定引入报名，使有效报名成为观看已发布课程的前置条件。
目标是一个最小可验证版本。
该版本学员自主管理报名，已有账号和课程在升级与重启后保持不变。

## 决策

本决定覆盖报名模型、自助管理、观看资格、公开浏览和数据升级。

### 报名模型

- 报名表示一个账号与一门课程之间的学习关系。
- 同一账号对同一课程至多有一条报名记录。
- 本决定中的“学员”指在相应课程上持有报名记录的账号，而不是账号的角色字段。
- 任何已登录账号都可以报名，包括管理员。
- 管理员报名只为其本人增加报名，不获得查看或操作他人报名的能力。
- 只有已发布课程可以报名。
- 报名人数不设上限，一门课程可以被任意数量的账号报名。
- 不设候补、审批、支付、截止时间或名额管理流程。
- 一个账号可以报名多门课程，不设课程数量上限。
- 报名即时生效，无需管理员确认。
- 有效报名指当前账号对该课程存在报名记录。
- 取消报名会删除该记录，是报名失效的唯一方式。
- 本版本不自动过期，也不因课程下架而删除报名。
- 课程编辑不改变报名记录，报名继续有效。
- 取消后可以重新报名，重新报名按新的报名时间生效。
- 重复报名和重复取消均为幂等操作，不产生重复记录，也不报错。
- 每条报名记录至少标识账号、课程和报名时间。

### 自助管理

- 学员只能查看和管理自己的报名，不能查看或操作他人的报名。
- 报名操作以当前会话账号为唯一主体，客户端不能指定其他账号或报名编号。
- “我的报名”列出当前账号的全部报名，包括课程已下架的报名。
- 列表显示课程标题、报名时间和课程状态，已发布课程提供详情入口，并提供取消报名操作。
- 课程已下架时，列表标记为“已下架”，不提供观看或课程详情入口。
- 课程重新发布后，该报名恢复为可观看状态，无需重新报名。
- 本版本的管理仅包括取消报名，不提供修改报名信息或转让报名。
- 本版本不提供管理员代报名、报名统计或报名名单管理。

### 观看资格

- 取得新的播放地址需要同时满足三个条件：已登录、对课程持有有效报名、课程已发布。

| 情形 | 课程详情 | 取得新播放地址 |
| --- | --- | --- |
| 未登录 | 已发布课程可见，未发布或不存在为 404 | 拒绝，提示登录 |
| 已登录、未报名，课程已发布 | 可见 | 拒绝，提示报名 |
| 已登录、有效报名，课程已发布 | 可见 | 允许 |
| 已登录，课程不存在或未发布 | 对外不存在 | 拒绝，按不存在处理 |

- 未登录的播放请求统一提示登录，不判断课程是否存在或已发布。
- 已登录请求中，课程不存在或未发布时统一按不存在处理，避免泄露草稿。
- 课程页的观看入口状态与播放接口使用同一套资格判断，前端隐藏不能替代服务端检查。
- 播放地址签发后即为授权，在地址到期前对持有者始终可读。
- 取消报名或课程下架不影响已签发地址的读取。
- 取消报名或课程下架后，新的播放地址立即停止签发。
- 撤销在已签发地址到期后完全生效，默认最长延迟为一个播放地址有效期。
- 本版本不记录学习进度、观看时长或完成状态。

### 公开浏览

- 课程目录、课程详情、课程封面和公开课程接口继续对未登录访客开放。
- 报名不是浏览课程详情的前提。
- 未登录访客可以查看课程介绍、讲师、难度和时长等公开信息，但不能取得播放地址。
- 登录但未报名的账号同样可以浏览课程详情，并在课程页看到报名入口。
- 报名和“我的报名”需要登录。
- 未登录访问报名或“我的报名”时，按现有登录流程回到原页面。
- 未发布课程不出现在公开目录和公开详情中，也不对未报名账号可见。

### 数据与升级

- 报名记录与账号、课程、会话保存在同一个 SQLite 数据库中。
- 服务重启后报名记录仍然有效。
- 登录会话仍按现有规则过期，重新登录后报名仍然有效。
- 数据库升级通过新增编号迁移完成，不修改已执行的迁移。
- 升级只新增报名存储，不重建或清空已有账号、课程、会话和配置。
- 升级不自动为既有学员补报名。
- 既有账号首次观看前需要自行报名。
- 备份和恢复沿用现有数据库备份机制，报名数据随数据库一起备份和恢复。
- 本版本不增加新的运行时依赖、外部服务或构建步骤。

### 本版本范围

| 包含 | 不包含 |
| --- | --- |
| 不限人数的自助报名与取消 | 支付、审批、名额、候补、截止时间 |
| 查看和管理自己的报名 | 查看他人报名、管理员代报名、报名名单 |
| 已发布课程的观看资格校验 | 学习进度、观看记录、证书、通知 |
| 课程目录和详情的公开浏览 | 按报名状态隐藏已发布课程 |
| 报名持久化、迁移与重启恢复 | 多班级、多期次、分组或课程包 |

## 影响

### 行为变化

- 已登录账号不再能直接观看已发布课程，必须先报名。
- 这是本版本对现有观看行为的唯一收紧。
- 课程目录和课程详情保持公开，未登录访客的浏览路径不变。
- 管理员如需观看课程，应像普通账号一样为自己报名。
- 取消报名或课程下架不会使已经取得的播放地址立刻失效，但会在地址到期后阻止续期。

### 可验证结果

- 未登录访客可以打开课程目录和课程详情，但取得播放地址时被拒绝并要求登录。
- 已登录但未报名的账号可以打开课程详情，但取得播放地址时被拒绝并要求报名。
- 报名后可以取得播放地址并读取视频，取消报名后不能取得新的播放地址。
- 多个账号可以报名同一门课程，且全部成功。
- 两个账号各自只能看到自己的报名，且无法取消对方的报名。
- 重复报名不会产生第二条报名，重复取消不会报错。
- 服务重启后，已有报名仍可用于观看，已有账号和课程保持不变。
- 课程下架后不能取得新的播放地址，重新发布后无需重新报名即可继续观看。
- 取消报名或课程下架后，已签发的播放地址在到期前仍可读取，到期后不可续期。

### 取舍

- 以报名记录是否存在作为“有效报名”的唯一判据，不引入状态机，换取最小实现和可验证性。
- 以短时播放地址作为授权载体，换取视频读取不依赖会话。
- 代价是取消报名后存在最长一个播放地址有效期的撤销延迟。
- 不自动补报名，确保报名是学员的明确行为。
- 不提供管理员报名管理，保持学员自助边界。
- 课程下架后保留报名，避免临时下架导致学员丢失学习关系。
- 后续确有运营需求时，再以新的决策扩展。
