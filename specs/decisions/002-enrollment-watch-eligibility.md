# DR-002: 报名约束下的观看资格

## 状态

提议

## 背景

- 当前已登录用户可取得已发布课程的限时播放地址，包括管理员。
- 当前播放地址本身就是授权，未过期时不带登录会话也可读取视频，课程下架后旧地址仍可读取。
- 新需求要求只有已登录且有效报名的学员才能观看已发布课程，仅限制新播放地址的签发不足以兑现该要求。

## 决策

### 统一观看条件

- 允许观看必须同时满足：当前用户已登录、身份为学员、对该课程有有效报名、课程当前已发布。
- 有效报名采用 [DR-001](001-self-service-enrollment.md) 的定义：报名成功且未取消，不设有效期。
- 页面观看状态、播放地址签发和视频读取均使用 `src/playback.js` 中同一个观看资格检查。
- 视频仍只能通过有效播放授权读取，签名地址不能替代当前登录身份和观看资格检查。
- 视频读取检查覆盖普通读取、范围读取和仅请求响应头的情形，不能通过直接调用接口绕过资格限制。

| 情形 | 观看结果 |
| --- | --- |
| 未登录 | 不允许观看，已发布课程仍可公开浏览 |
| 已登录学员未报名或已取消报名 | 不允许观看，可报名当前已发布课程 |
| 已登录学员有有效报名且课程已发布 | 允许观看 |
| 管理员 | 不允许观看，不设置管理员豁免，保留课程管理能力 |
| 课程未发布或不存在 | 不允许观看，不开放公开课程详情 |

### 资格变化与生效边界

- 取消报名、退出登录、会话失效或课程取消发布后，后续播放地址申请和视频读取请求不再获准。
- 已签发且尚未过期的地址也不能绕过变化后的观看条件。
- 分享播放地址不会授予接收者观看资格，接收者也必须满足全部观看条件。
- 已传输或已缓冲的数据无法收回，本版本不承诺主动切断已开始的响应。
- 本版本不提供跨标签页状态即时推送，新的请求以服务端当前状态为准。
- 课程取消发布不取消已有报名，但暂停其观看资格；再次发布后，仍未取消的报名恢复观看资格。
- 课程下架期间，学员仍可按 [DR-001](001-self-service-enrollment.md) 查看并取消自己的报名。

## 影响

- 原有“登录即可观看”和“持有未过期地址即可读取”的行为将改变，相关页面提示、接口文档和测试需要随实现更新。
- 管理员不再因登录身份获得观看资格，管理员试听不属于本版本。
- 视频读取需要同时携带有效登录会话和播放授权。
- 可通过报名前后观看、取消后的旧地址读取、退出后的读取、无会话读取及下架后重新发布验证资格变化。
- 既有范围读取、播放授权有效期和过期后重新申请的能力仍保留，但重新申请及读取必须满足当前观看条件。
