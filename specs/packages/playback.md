# playback: 报名约束的播放授权与读取

## 意图

本包依据 [DR-002](../decisions/002-enrollment-watch-eligibility.md) 定义统一观看资格、限时授权和媒体读取。
保留短期签名、视频范围读取与既有错误语义，替换登录即可观看及地址本身即可授权的旧行为。

## 外部行为

### playback-1

当页面或接口判定观看资格，播放服务应以当前会话身份 [[identity-3](identity.md#identity-3)]、课程公开可用性 [[courses-3](courses.md#courses-3)]和本人报名有效性 [[enrollment-6](enrollment.md#enrollment-6)]判定是否允许观看：

| 条件 | 结果 |
| --- | --- |
| 未登录或会话失效 | 拒绝，401 |
| 已登录但不是学员 | 拒绝，403 |
| 学员访问未发布、不存在或无效编号课程 | 拒绝，404 |
| 学员访问已发布课程但没有有效报名 | 拒绝，403 |
| 学员已登录、有有效报名且课程已发布 | 允许 |

- 条件按表从上到下判定，管理员不享有观看豁免。
- 页面状态、播放授权申请及普通、Range、HEAD 媒体请求均经过 `src/playback.js` 中同一个观看资格检查，不另写一套资格规则。

### playback-2

当请求 `POST /api/courses/:id/play`，播放服务应经过业务请求边界 [[web-contract-1](web-contract.md#web-contract-1)]后，依据当前观看资格 [[playback-1](#playback-1)]签发或拒绝播放地址：

- 允许时返回 200 和 {url, expiresAt}，默认有效期为 60000 毫秒，expiresAt 为毫秒时间戳。
- 地址形式保留 `/media/:id?expires=…&signature=…`，授权保护课程编号和到期时间。
- 拒绝时使用资格检查状态和中文错误格式 [[web-contract-3](web-contract.md#web-contract-3)]，不返回授权。

### playback-3

当通过 `/media/:id` 请求视频，播放服务应在输出任何视频数据前同时验证当前观看资格 [[playback-1](#playback-1)]与签名授权：

- 签名缺失、格式错误或被篡改时拒绝，资格有效时返回 403。
- 授权到期时拒绝，资格有效且签名正确时返回 410。
- 资格、签名和时效均有效后，视频缺失或文件不合法返回 404。
- 仅持有地址不能绕过资格检查，分享地址的接收者也必须具备自身观看资格。
- 本规则覆盖 GET、Range 和 HEAD，不提供可绕过授权的本地文件名或静态资源读取入口。

### playback-4

如果已签发播放地址，当发生取消报名、退出登录、会话失效或课程下架，播放服务应从后续请求起重新判定当前观看资格 [[playback-1](#playback-1)]，拒绝不再有资格者使用旧地址或申请新地址：

- 不等待旧地址到期。
- 不承诺收回已传输或缓冲数据，也不承诺中断已开始的响应。
- 课程重新发布后，仍有有效报名的已登录学员可重新获得观看授权。

### playback-5

如果当前观看资格 [[playback-1](#playback-1)]和签名授权 [[playback-3](#playback-3)]均有效，当请求视频数据，播放服务应保留 MP4 读取契约：

- 无 Range 的 GET 返回 200、video/mp4、Accept-Ranges: bytes、Content-Length 与完整字节。
- 合法单段 Range 返回 206、Content-Range 与对应字节，支持起止、开放结尾和后缀范围，结束位置超过文件时截断到末尾。
- 起点超出文件或零长度后缀返回 416 与 `Content-Range: bytes */<size>`。
- 无法识别、逆序或多段 Range 按完整文件响应。
- HEAD 保留对应状态与响应头，不返回视频正文。

## 验证

### playback-6

给定游客、管理员、未报名、已报名、已取消和会话过期学员，当集成测试交叉组合课程发布状态并访问授权及媒体入口，测试应通过集成请求和调用链检查断言各入口经过同一资格检查、只允许完整满足条件的学员且拒绝状态与矩阵一致 [[playback-1](#playback-1)]。

### playback-7

给定真实登录与报名流程，当集成测试申请播放地址及对已授权地址篡改课程编号或到期时间，测试应断言成功字段和默认时限正确、篡改不获授权且无资格申请不返回地址 [[playback-2](#playback-2)]。

### playback-8

给定真实有效报名和播放授权，当集成测试无 Cookie 读取、分享给未报名与已报名学员、篡改签名、使用过期授权、读取缺失视频及尝试文件名或静态路径绕过，测试应断言只有当前有资格且授权有效的请求读取成功，并分别验证 GET、Range、HEAD [[playback-3](#playback-3)]。

### playback-9

给定尚未到期的真实播放地址，当集成测试分别取消报名、退出、使会话到期及下架课程后立即再次读取并申请授权，测试应断言后续请求被拒绝，再发布后未取消报名的学员恢复观看而已取消者仍被拒绝 [[playback-4](#playback-4)]。

### playback-10

给定有资格的学员与真实 MP4，当集成测试读取全文件、起止范围、开放结尾、后缀、越界、逆序、多段和 HEAD，测试应断言状态、响应头、实际字节与无正文约定一致 [[playback-5](#playback-5)]。
