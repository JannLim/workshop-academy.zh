# enrollment: 学员报名生命周期

## 意图

本包依据 [DR-001](../decisions/001-self-service-enrollment.md) 定义自助报名、取消、私有列表和有效性查询。
本包不提供报名历史、代报名、收费、审批、人数限制或候补能力。
本包描述业务操作及结果，新增接口的路径和响应字段命名留给实现设计，页面与直调接口必须使用相同操作规则。

## 外部行为

### enrollment-1

当收到报名业务请求，报名服务应执行请求边界 [[web-contract-1](web-contract.md#web-contract-1)]、JSON 对象读取 [[web-contract-2](web-contract.md#web-contract-2)]和中文错误输出 [[web-contract-3](web-contract.md#web-contract-3)]。

### enrollment-2

当请求报名、取消或查询个人报名，报名服务应使用当前会话身份 [[identity-3](identity.md#identity-3)]限定为学员本人：

- 未登录或会话失效返回 401，管理员返回 403。
- 归属只来自当前身份，客户端提供的用户标识不能改变操作归属。
- 指向他人报名的请求不返回他人报名信息、不改变他人报名；不提供管理员代办入口。

### enrollment-3

如果请求者是已登录学员，当主动报名课程，报名服务应仅对当前公开可用的课程 [[courses-3](courses.md#courses-3)]建立本人有效报名，持久化成功后才报告成功 [[continuity-1](continuity.md#continuity-1)]：

- 成功后立即生效，无费用、审批、报名期限或名额限制。
- 草稿、不存在或编号无效的课程返回 404 且不创建报名。
- 从未报名与已取消报名的学员均可报名。

### enrollment-4

如果请求者是已登录学员且课程当前公开可用 [[courses-3](courses.md#courses-3)]，当重复或并发提交该课程的报名请求，报名服务应沿用本人报名流程 [[enrollment-3](#enrollment-3)]返回成功并保持该学员对该课程仅一份有效报名，不影响其他学员或其他课程。

### enrollment-5

如果请求者是已登录学员，当取消自己的报名，报名服务应在持久化成功后 [[continuity-1](continuity.md#continuity-1)]将该报名置为无效，并允许已下架课程的报名被取消：

- 重复取消保持无效，不恢复报名或影响其他报名。
- 未有效报名的课程取消请求不得创建有效报名。

### enrollment-6

当查询某账号对某课程的报名有效性，报名服务应仅在该账号成功报名且未取消时返回有效，不设置时间到期条件，并独立于会话存续和课程发布状态。

### enrollment-7

如果请求者是已登录学员，当查询个人报名列表，报名服务应只返回本人的当前有效报名 [[enrollment-6](#enrollment-6)]及识别课程和可用性所需的信息：

- 有效报名全部可查询，不因课程下架而遗漏，已取消记录不返回。
- 每项可识别对应课程，并区分当前公开可用课程 [[courses-3](courses.md#courses-3)]与暂不可用课程。
- 未发布课程不通过该列表开放完整课程详情、视频文件或播放授权。
- 不返回其他学员的身份、报名或报名人数，没有有效报名时返回空集合。

## 验证

### enrollment-8

给定真实报名接口，当集成测试发送跨源、错误 Content-Type、非法 JSON 和超限请求，测试应断言请求被拒绝且报名状态不变 [[enrollment-1](#enrollment-1)]。

### enrollment-9

给定两个学员和管理员的真实会话，当集成测试伪造用户标识、交叉操作报名并以游客和管理员直调接口，测试应断言他人数据不泄露、不改变且游客为 401、管理员为 403 [[enrollment-2](#enrollment-2)]。

### enrollment-10

给定真实已发布课程和草稿，当集成测试以两个学员分别报名、取消后再报并尝试报名草稿及无效编号，测试应断言合格请求立即生效且彼此无名额竞争，不可用课程返回 404 [[enrollment-3](#enrollment-3)]。

### enrollment-11

给定同一学员与其他学员的报名，当集成测试并发和顺序重复提交同课报名，测试应断言请求成功且每个学员每门课最多一份有效报名 [[enrollment-4](#enrollment-4)]。

### enrollment-12

给定两个学员对同一课程的报名，当集成测试取消本人报名、重复取消及取消下架课程报名，测试应断言本人报名持续无效、其他学员报名保持有效且没有新增有效报名 [[enrollment-5](#enrollment-5)]。

### enrollment-13

给定已报名、未报名和已取消的账号课程组合，当集成测试经过退出重登、课程下架与重新发布后查询报名结果，测试应断言只有未取消的成功报名持续有效且未因时间或发布状态被取消 [[enrollment-6](#enrollment-6)]。

### enrollment-14

给定两个学员的多门课程报名、取消记录与下架课程，当集成测试查询各自列表，测试应断言集合完整且仅含本人有效报名、可区分下架课程、不泄露完整草稿内容或他人信息，空列表为空集合 [[enrollment-7](#enrollment-7)]。
