# watch: 观看资格与公开浏览

## 意图

本规约包使已登录且对课程持有有效报名的账号能够取得已发布课程的播放授权并观看视频，同时保持课程目录和详情公开浏览。
它负责观看资格、播放授权签发和视频读取的访问控制，不负责报名的创建、取消或持久化。
本规约包依赖 enrollment 规约包提供的有效报名行为，具体绑定见观看资格条目。
课程发布、下架和管理沿用现有行为。
本规约包不记录学习进度、观看时长或完成状态。

## 外部行为

### watch-1

当请求取得某课程的播放地址，观看资格应同时满足：账号已登录、账号对该课程持有有效报名 [[enrollment-1](enrollment.md#enrollment-1)]、课程已发布：

| 情形 | 取得新播放地址 |
| --- | --- |
| 未登录 | 401，提示登录 |
| 已登录、未报名，课程已发布 | 403，提示报名 |
| 已登录、有效报名，课程已发布 | 200，签发播放地址 |
| 已登录，课程不存在或未发布 | 404，按不存在处理 |

- 未登录的播放请求统一提示登录，不判断课程是否存在或已发布。
- 已登录请求中，课程不存在或未发布时统一按不存在处理，避免泄露草稿。
- 报名资格与账号角色无关，管理员没有观看豁免，必须为自己报名。
- 取消报名后，该账号不再满足有效报名条件 [[enrollment-3](enrollment.md#enrollment-3)]。

### watch-2

当访客访问课程目录或已发布课程详情，公开课程信息应保持可见，与访客是否登录及是否报名无关：

- 课程目录、课程详情、课程封面和公开课程接口对未登录访客开放。
- 未登录访客可以查看课程介绍、讲师、难度和时长等公开信息。
- 登录但未报名的账号同样可以浏览课程详情。
- 未发布课程不出现在公开目录和公开详情中，也不对未报名账号可见。
- 未发布课程仍对管理员的管理页面可见。

### watch-3

当系统签发播放地址，系统应返回具有有限有效期的签名地址，该地址本身即为视频读取授权：

- 播放地址默认有效期为 60 秒。
- 视频只能通过有效播放地址读取。
- 在有效期内，携带该地址即可读取视频，不需要登录会话或报名状态。
- 视频读取支持 Range 和 HEAD 请求，无效范围返回 416。
- 签名无效返回 403，地址过期返回 410，视频缺失返回 404。

### watch-4

给定播放地址已签发，当报名被取消或课程下架，已签发地址应在到期前保持可读，且系统应停止签发新地址：

- 取消报名后，该账号不能取得新地址，但已签发地址在到期前可读 [[enrollment-3](enrollment.md#enrollment-3)]。
- 课程下架后，不能取得新地址，但已签发地址在到期前可读。
- 撤销在已签发地址到期后完全生效，默认最长延迟为一个播放地址有效期。
- 课程重新发布后，持有有效报名 [[enrollment-7](enrollment.md#enrollment-7)] 的账号无需重新报名即可取得新地址。
- 地址过期后，满足当前观看资格的账号可以重新取得地址。

### watch-5

给定课程页展示观看入口，页面状态应与播放地址签发使用同一套资格判断：

- 未登录时显示登录提示。
- 已登录但未报名时显示报名提示。
- 已登录且持有有效报名、课程已发布时显示开始观看入口 [[enrollment-1](enrollment.md#enrollment-1)]。
- 课程不存在或未发布时按不存在处理。
- 前端隐藏不能替代服务端检查，直接调用取得播放地址的接口应得到相同结果。

## 验证

### watch-6

当运行公开浏览系统测试，测试应启动真实服务并断言以下公开访问行为：

- 未登录访客可以打开课程目录和已发布课程详情，并看到公开课程信息 [[watch-2](#watch-2)]。
- 登录但未报名的账号同样可以打开课程详情，并看到公开课程信息 [[watch-2](#watch-2)]。
- 未发布课程在公开目录和详情中返回不存在 [[watch-2](#watch-2)]。
- 未登录访客可以直接调用公开课程接口读取已发布课程 [[watch-2](#watch-2)]。

### watch-7

当运行观看资格集成测试，测试应启动真实服务并断言以下访问矩阵：

- 未登录请求取得已发布课程的播放地址被拒绝并要求登录 [[watch-1](#watch-1)]。
- 已登录但未报名的账号请求取得已发布课程的播放地址被拒绝并要求报名 [[watch-1](#watch-1)]。
- 已登录且持有有效报名的账号请求取得已发布课程的播放地址成功 [[watch-1](#watch-1)]。
- 已登录账号请求取得不存在或未发布课程的播放地址按不存在处理 [[watch-1](#watch-1)]。
- 管理员未报名时请求取得播放地址被拒绝，报名后成功 [[watch-1](#watch-1)]。

### watch-8

当运行播放授权系统测试，测试应启动真实服务并断言以下播放地址行为：

- 签发的播放地址具有有限有效期，并在有效期内可读取视频 [[watch-3](#watch-3)]。
- 不带登录会话读取有效播放地址成功 [[watch-3](#watch-3)]。
- 视频不能通过播放地址以外的路径读取 [[watch-3](#watch-3)]。
- 播放地址支持 Range 和 HEAD 请求，无效范围返回 416 [[watch-3](#watch-3)]。
- 签名无效返回 403，地址过期返回 410，视频缺失返回 404 [[watch-3](#watch-3)]。

### watch-9

当运行资格变更系统测试，测试应启动真实服务并断言以下撤销边界：

- 取消报名后，新的播放地址请求被拒绝，已签发地址在到期前仍可读取 [[watch-4](#watch-4)]。
- 课程下架后，新的播放地址请求按不存在处理，已签发地址在到期前仍可读取 [[watch-4](#watch-4)]。
- 已签发地址过期后返回 410，满足当前观看资格的账号可以重新取得地址 [[watch-4](#watch-4)] [[watch-3](#watch-3)]。
- 课程重新发布后，持有有效报名的账号无需重新报名即可取得新地址 [[watch-4](#watch-4)]。

### watch-10

当运行课程页与接口一致性系统测试，测试应启动真实服务并断言以下页面状态：

- 未登录访客的课程页显示登录提示，且不显示开始观看入口 [[watch-5](#watch-5)]。
- 已登录未报名账号的课程页显示报名提示，且不显示开始观看入口 [[watch-5](#watch-5)]。
- 已登录有效报名账号的课程页显示开始观看入口 [[watch-5](#watch-5)]。
- 直接调用取得播放地址的接口得到与页面状态一致的资格结果 [[watch-5](#watch-5)]。
